Aide

Construire la frise

  • Événement : quelque chose qui se passe à une date (ex. : 14 juillet 1789).
  • Période : quelque chose qui dure, avec un début et une fin (ex. : la Première Guerre mondiale).
  • Pour les dates avant notre ère, cochez av. J.-C. (ou tapez une année négative).
  • Double-cliquez sur un espace vide de la frise pour ajouter un événement à cet endroit.
  • Cliquez sur un élément pour lire son texte détaillé ; double-cliquez pour le modifier.
  • Pour ajouter une image : glissez-la dans la fenêtre de modification, ou copiez-la (clic droit → « Copier l’image ») puis collez-la avec Ctrl+V. Pensez à indiquer la source !

Se déplacer

  • Molette de la souris : zoomer / dézoomer. Maj + molette : défiler de gauche à droite.
  • Glisser avec la souris (ou le doigt) : se déplacer. Pincer à deux doigts : zoomer.
  • Tout voir : afficher toute la frise d’un coup.

Enregistrer et rouvrir

  • Enregistrer crée un fichier .html qui contient toute la frise, images comprises.
  • Pour rouvrir la frise : double-cliquez simplement sur ce fichier. Il s’ouvre dans le navigateur, prêt à être modifié.
  • Ce fichier peut être déposé sur l’ENT, envoyé par messagerie ou copié sur une clé USB.
  • Le travail est aussi sauvegardé automatiquement dans le navigateur : en cas d’oubli, il est proposé à la réouverture (« Travaux récents »).
  • Frises FriseChronos : « Fichier → Importer une frise FriseChronos… » convertit un fichier enregistré sur frisechronos.fr (événements, périodes, images). Enregistrez ensuite la frise au nouveau format.
  • Plusieurs frises FriseChronos d’un coup : « Fichier → Convertir un dossier de frises FriseChronos… ». Choisissez votre dossier de travail : tous les fichiers .bin de ses sous-dossiers sont convertis et enregistrés ensemble dans ce dossier (les fichiers déjà convertis ne sont pas remplacés).
  • Avec Edge ou Chrome, après le premier enregistrement, Ctrl+S met directement à jour le même fichier.
